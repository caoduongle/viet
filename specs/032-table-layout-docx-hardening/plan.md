# Implementation Plan: Table Layout Robustness, Geometry Scaling & DOCX Import Hardening

**Input**: Feature specification from `specs/032-table-layout-docx-hardening/spec.md`

## Summary

This feature resolves 5 critical table layout and DOCX conversion defects identified during repository review:
1. **P1: Table Pagination Boundary Clamping**: Implement a two-stage pagination strategy in `TableLayoutEngine` that defers oversized merged row groups to new pages when they exceed remaining page space, and cleanly partitions/clamps strokes when a group exceeds an entire page, guaranteeing 100% of strokes lie within printable bounds.
2. **P1: Math Formula Vertical Metrics Scaling**: Normalize formula ascent and descent by multiplying by $S \times \text{scale\_mult}$ inside `DocumentLayoutEngine.cell_inlines_formatter`, eliminating cell border collisions across all handwriting scales.
3. **P2: Long Unbroken Token Character Wrapping**: Integrate character-level wrapping into `cell_inlines_formatter` so long URLs and identifiers wrap onto multiple lines inside the column instead of bleeding across column borders.
4. **P2: DOCX Table Occupancy Grid & Nested Order**: Use a 2D occupancy grid in `bridge.py` to calculate logical column count and align Markdown columns; iterate `c._tc.iterchildren()` in `docx_importer.py` to preserve document block order.
5. **P3: Web Modal Header Controls & Test Tightening**: Fix the "Has header row" checkbox in `webapp/js/write.js`, and tighten tests to verify uncompressed `.xopp` XML stroke coordinates inside cell bounding boxes.

## Technical Context

**Language/Version**: Python 3.10+ (supporting Python 3.10, 3.11, 3.12, 3.13, 3.14 via Pyodide), JavaScript ES2022 (Node.js 20+, browser ESM)

**Primary Dependencies**: Zero external dependencies for core Python layout (`chuviettay`), `python-docx` (optional docx importer), standard browser DOM/SVG APIs, Playwright (for E2E tests)

**Storage**: In-memory document AST, `.xopp` (gzipped XML), IndexedDB (web client)

**Testing**: `pytest` (with `pytest-timeout`), `node:test`, `@playwright/test`

**Target Platform**: Linux, macOS, Windows desktop (CLI/Tkinter), Web client (Pyodide WASM in Web Worker)

**Project Type**: Python library, CLI, desktop GUI, static web application

**Performance Goals**: Layout latency under 100ms for typical tables (< 50 rows), zero pagination hangs or regressions

**Constraints**:
- Strict MVC boundaries enforced by `tests/test_architecture.py` (model has no UI/controller deps; view/cli only access controller).
- Golden Master hash invariance for Plain paper (`tests/test_golden_master_real_path.py`).
- 100% of handwritten and border strokes within printable page boundaries ($y \le \text{page\_height} - 60.0$).

**Scale/Scope**: 5 core files modified (`table_layout.py`, `engine.py`, `bridge.py`, `docx_importer.py`, `write.js`), ~6 targeted test suites.
