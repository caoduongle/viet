# Implementation Plan: Table Continuation, Rowspan Stability, and Geometry Safety Hardening

**Branch**: `035-table-continuation-and-geometry-safety` | **Date**: 2026-10-13 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/035-table-continuation-and-geometry-safety/spec.md`

## Summary

This feature resolves remaining edge cases and geometry hazards identified during repository review of commit `ca6972e`:
1. **Physical Stroke Containment & Guaranteed Page Clamping (P1)**: Enforces hard coordinate bounding ($y \le \text{max\_page\_y}$) and proportional downscaling for indivisible elements, replacing misleading clamping notices with truthful diagnostic warnings.
2. **Stable Cell Identity Tracking (P1)**: Adds persistent `source_cell_id` to `TableCell` and `LaidOutCell` so continuation lines map accurately to the origin cell across 3+ page slices with `rowspan > 1`.
3. **Explicit Non-Overlapping Rowspan Partitioning (P2)**: Partitions `rowspan` explicitly between the origin cell and continuation cells during dynamic row splitting in `TableLayoutData.slice_page()`, eliminating grid collisions and interior divider lines.
4. **Whole-Word Aware Hybrid Token Wrapping (P2)**: Enhances `Writer.measure_text_width()` to inspect `bank.words` before character splitting, and processes long tokens in $O(N)$ linear time without mutating synthesizer state.
5. **Synchronized Line Height under `auto_xh` (P2)**: Calculates finalized scale `self.S` and `self.effective_wscale` prior to `self.line_h`, ensuring safe anti-collision floors scale proportionally with character size.
6. **Deterministic Labeled Line Verification & Decoupled CI Benchmarks (P3)**: Adds tests verifying complete sequences of labeled line identifiers (`LINE_0001` .. `LINE_0060`) and replaces wall-clock threshold tests with invocation call counts.

## Technical Context

**Language/Version**: Python 3.10+  
**Primary Dependencies**: Standard library (`math`, `random`, `dataclasses`), `chuviettay` core engine. (No new third-party dependencies introduced).  
**Storage**: In-memory IR structures and `.xopp` XML output file generation.  
**Testing**: `pytest` (test execution), with custom XML inspection and geometry assertion utilities.  
**Target Platform**: Cross-platform (Windows, Linux, macOS).  
**Project Type**: Desktop CLI & GUI handwriting synthesis engine.  
**Performance Goals**: Pure linear $O(N)$ token wrapping measurement; $O(1)$ grid lookup; sub-second multi-page table pagination.  
**Constraints**: 100% strict adherence to physical page margins ($y \le \text{max\_page\_y}$); zero dropped or duplicated lines; 100% clean MVC compliance (`test_architecture.py`).  
**Scale/Scope**: Tables spanning arbitrary numbers of pages (tested on 3-5+ pages) with arbitrarily deep `rowspan` and `colspan` merges.
