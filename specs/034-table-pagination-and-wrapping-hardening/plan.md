# Implementation Plan: Table Pagination, Line Spacing Anti-Collision, Math Accents, and Geometry Hardening

**Branch**: `034-table-pagination-and-wrapping-hardening` | **Date**: 2026-10-12 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/034-table-pagination-and-wrapping-hardening/spec.md`

## Summary

This plan outlines the technical design and phased implementation to harden table pagination, enforce physical anti-collision floors on line spacing, naturally anchor mathematical accents, synchronize row indices during continuation slicing, and execute single-pass zero-mutation token wrapping.

Key technical deliverables:
1. **Lossless Bottom-Margin Slicing**: Eliminate `break` content dropping at `line_bottom_y > max_page_y` by implementing active remainder rollover to continuation cells.
2. **Physical Anti-Collision Line Spacing Floor**: Enforce `safe_line_floor` on `effective_line_h` and table row heights, ensuring that setting `line=1.0pt` or small positive values never causes overlapping text or border strike-through.
3. **Natural Math Accent Anchoring**: Tighten optical gaps for mathematical accents ($\bar{x}, \hat{x}, \tilde{x}, \vec{x}$) to $0.08 - 0.18 \times xh$ and bound ascent metrics to prevent erratic baseline jumps.
4. **Row Index and Span Synchronization**: Re-index cells and update multi-row spans (`rowspan`) when dynamic continuation rows are created, maintaining exact `BorderLookupGrid` alignment.
5. **Single-Pass Zero-Mutation Token Wrapping**: Compute candidate break points in $O(N)$ linear time using pure width estimation without mutating `Writer` state.
6. **Intentional Blank Line Retention**: Preserve empty lines and blank paragraphs in table cells.
7. **Strict Geometry Containment**: Add invariant test assertions for exact line preservation ($N_{\text{rendered}} == N_{\text{expected}}$) and post-transformation stroke point bounding box containment.

## Technical Context

**Language/Version**: Python 3.11+  
**Primary Dependencies**: Standard library (`math`, `random`, `dataclasses`), existing `chuviettay` modules (`model`, `layout`, `math`, `browser`)  
**Storage**: In-memory document IR, `.xopp` XML output, compressed JSON letter/word banks  
**Testing**: `pytest` (unit, integration, golden master regression, architecture checks)  
**Target Platform**: Windows, Linux, macOS (cross-platform desktop and browser bridge)  
**Project Type**: Desktop CLI / GUI application & Browser Bridge core rendering library  
**Performance Goals**: 
- Token wrapping executes in $< 5\text{ms}$ for strings up to 1,000 characters ($O(N)$ complexity).
- Zero speculative handwriting synthesis during width measurement.  
**Constraints**: 
- 100% text preservation across multi-page table splits.
- Zero architectural MVC violations (enforced by `test_architecture.py`).
- Bit-exact Golden Master regression preservation (`test_golden_master_real_path.py`).  
**Scale/Scope**: Core engine hardening affecting `chuviettay/layout/`, `chuviettay/math/`, and tests.
