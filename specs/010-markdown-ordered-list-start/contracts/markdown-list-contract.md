# Interface Contract: Markdown Ordered List Start Numbering

**Feature Branch**: `010-markdown-ordered-list-start`
**Date**: 2026-09-30
**Spec**: [spec.md](../spec.md)

---

## 1. Markdown Token Importer Contract

### Input Contract: `ordered_list_open` Token
The importer receives a token stream generated by `MarkdownIt.parse(clean_text)`.

For any token `tok` where `tok.type == "ordered_list_open"`:
- `tok.attrGet("start")` or `tok.attrs.get("start")` may contain:
  - `None`: List starts at the default index `1`.
  - An integer `N` (e.g. `4`): List starts at `N`.
  - A string representation of an integer (e.g. `"4"`): List starts at `int("4") = 4`.
  - Malformed value (e.g. `"abc"`, `None`, object): Importer MUST fall back to `1`.

### Output Contract: `ListBlock`
`MarkdownImporter.import_text(text)` returns `ImportResult`:
```python
@dataclass
class ImportResult:
    document: Document
    warnings: list[str] = field(default_factory=list)
    unsupported_features: list[str] = field(default_factory=list)
```

Within `document.blocks`:
- For every ordered list parsed, `ListBlock` MUST be instantiated with `ordered=True` and `start=N`, where $N$ matches the resolved start index.
- For every bullet list parsed, `ListBlock` MUST be instantiated with `ordered=False` and `start=1`.

## 2. Document Layout Engine Prefix Contract

### Input Contract: `ListBlock`
`DocumentLayoutEngine.render(document)` consumes blocks from `document.blocks`.

When encountering `block: ListBlock`:
```python
for idx, item_blocks in enumerate(block.items):
    pfx = f"{block.start + idx}. " if block.ordered else "- "
```

### Invariants:
1. Item at index $0$ receives prefix `f"{block.start}. "`.
2. Item at index $k$ receives prefix `f"{block.start + k}. "`.
3. Interrupted lists split across multiple `ListBlock` instances (e.g. Block 0: `start=1, items=3`; Block 2: `start=4, items=2`) produce continuous numbering without resetting:
   - Item 0, list 1: `1. `
   - Item 1, list 1: `2. `
   - Item 2, list 1: `3. `
   - (intervening block, e.g. Table)
   - Item 0, list 2: `4. `
   - Item 1, list 2: `5. `
